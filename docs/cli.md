# Command-line flags

Run `nano-coder --help` for a summary. The table below is generated from the flag table the argument parser uses.

The most used flags: `--login github-copilot`, `--list-models PROVIDER`, `--trajectory SESSION_ID [--json|--markdown]`, `--acp`, `--model provider/model` (or `AGENTIC_HARNESS_MODEL`), `--resume [SESSION|last]` (a handle, ID, unique ID prefix or title), `--name HANDLE`, `--list-sessions [--all] [--json]`,
`--config PATH`, `--verbosity LEVEL` (`-v`), `--sandbox off|workspace|read-only` (or `NANO_CODER_SANDBOX`),
`--allow RULE` and `--deny RULE` (repeatable; added to the config's rules), `--version` (`-V`).
